# 小星星故事屋 文档

## 项目概述

小星星故事屋是一个面向儿童的 Web 应用，旨在把大量有教育意义的寓言、成语、童话、神话、科普与品格故事，以赏心悦目、适合小朋友的界面呈现出来。小朋友可以按年龄段和分类挑故事，家长或孩子点击即可听到语音朗读，边听边看大字故事。

应用支持**按名字登录（无需密码）** 与**个人主页**：登录后可查看自己的收藏、最近听过与自我介绍。账号数据支持**双模式存储**——有后台服务时保存到服务器（按名字存为 JSON 文件），没有后台服务时自动保存到浏览器本地，任何部署形态都能正常使用。

**目标用户**:
- 3-12 岁的小朋友（通过年龄段筛选适配不同阅读能力）
- 陪伴孩子读故事的家长、老师

**核心价值**:
- **内容多而正**: 收录 360 余篇可公版使用的寓言、成语、童话、神话、科普、品格故事，每篇附寓意解读
- **好看又好用**: 明快的配色、圆润的大卡片、插画封面、动画反馈，专为小朋友的视觉与操作习惯设计
- **会讲故事的网站**: 基于浏览器语音合成（TTS）逐段朗读，支持暂停、继续、语速调节，适合低龄与识字量少的孩子
- **打开即用**: 纯前端、数据内置，一条命令本地预览，也可直接托管到任意静态服务器
- **账号可云端可本地**: 输入名字即可登录，有后台则资料存服务器，无后台则存浏览器，自动切换
- **可一键打包**: 提供 Go 单文件后台，用 `//go:embed` 内嵌全部前端资源，编译后单个可执行文件即可运行

## 技术选型

| 类别 | 选择 | 理由 |
|------|------|------|
| 构建工具 | Vite 5 | 启动快、配置简单、天然适合纯静态站点 |
| 前端框架 | React 18 + TypeScript | 组件生态成熟，类型系统保证故事数据结构与内容质量 |
| 路由 | React Router 6 | 首页 / 探索 / 故事详情 / 收藏 多页面导航 |
| 样式方案 | Tailwind CSS 3 + 自定义主题 | 快速实现圆润、明快、响应式的儿童向视觉 |
| 动画 | Framer Motion | 卡片入场、翻页、按钮反馈等轻量动画 |
| 状态管理 | Zustand + persist | 管理账号、收藏、阅读历史、字号语速等状态与本地持久化 |
| 账号存储 | 可选 Node 后台（`node:http`）或 Go 单文件后台 + 浏览器 localStorage | 双模式适配：有后台存 JSON 文件，无后台存本地，运行时自动探测 |
| 语音朗读 | Web Speech API (`speechSynthesis`) | 浏览器原生，无需后端与额外费用 |
| 故事数据 | 内置 TypeScript/JSON 数据模块 | 纯静态、可离线、随构建发布 |
| 插画 | 分类 SVG + 每篇主题色/图形封面 | 无外部依赖，保证离线与加载速度 |
| 部署 | 任意静态托管，或静态前端 + 可选后台服务（含 Go 单文件） | 构建产物为纯静态文件；Go 后台可用 `//go:embed` 把 dist 打进单个可执行文件 |

## 核心功能

### 1. 故事浏览与年龄段筛选
- **目的**: 让不同年龄、不同识字量的小朋友都能快速找到适合自己的故事
- **描述**: 首页按「启蒙 3-6 / 成长 6-9 / 探索 9-12」三个年龄段切换；每个年龄段下展示对应分类入口与精选故事

### 2. 分类与搜索
- **目的**: 在大量故事中快速定位内容
- **描述**: 支持按分类（寓言、成语、睡前、童话、神话、科普、品格）多维筛选，支持标题/标签/寓意关键词搜索，结果实时更新

### 3. 故事阅读页
- **目的**: 提供沉浸、护眼、易读的阅读体验
- **描述**: 大字号分段正文、插画封面、寓意卡片、阅读时长、字号与行距调节、上一篇/下一篇快速切换

### 4. 语音朗读
- **目的**: 把故事读给还不识字或喜欢听的孩子
- **描述**: 两种声音来源可切换——① 浏览器朗读（Web Speech API 逐段朗读，当前段高亮并自动滚动，支持播放/暂停/继续/停止与语速调节）；② 预生成音色（在服务端音色目录中选一个，播放对应 mp3，**无需登录**）。**仅带后端服务的部署支持音色**，纯前端部署只有浏览器朗读。选中音色但该篇缺音频时明确报错，不静默回退

### 5. 收藏与最近阅读
- **目的**: 让孩子和家长能快速回到喜欢的故事
- **描述**: 一键收藏、收藏列表页、首页展示「最近听过/读过」；登录后自动同步到当前存储（服务器或本地）

### 6. 登录与个人主页
- **目的**: 让小朋友拥有自己的故事屋，跨会话保存收藏与足迹
- **描述**: 输入名字即可登录，无需密码；个人主页展示头像、加入时间、自我介绍、收藏与最近听过，可更换头像和介绍；能连上后台时资料存入服务器，否则存入本机浏览器
